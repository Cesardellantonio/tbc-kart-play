# TBC Kart — play in the browser

**▶ Play: https://cesardellantonio.github.io/tbc-kart-play/**

Indoor kart racing in Three.js on ten circuits (the TBC home track plus nine kart-scale layouts inspired by F1: Monaco, Monza, Silverstone, Spa, Interlagos, Montréal, COTA, Red Bull Ring, Marina Bay). Grand Prix against five AI rivals at three levels, Time Attack against your best-lap ghost, or **Online**: create a room and race up to five friends live (peer-to-peer, AI fills the empty slots). Realistic kart physics: per-wheel load transfer and a solid rear axle, real tyre model with temperature, an engine with a centrifugal clutch, and a track that rubbers in. Keyboard, gamepad, or touch.

This repository only hosts the compiled game. Source: https://github.com/Cesardellantonio/tbc-kart
