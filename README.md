# TBC Kart — play in the browser

**▶ Play: https://cesardellantonio.github.io/tbc-kart-play/**

Indoor kart racing in Three.js on ten circuits (the TBC home track plus nine kart-scale layouts inspired by F1: Monaco, Monza, Silverstone, Spa, Interlagos, Montréal, COTA, Red Bull Ring, Marina Bay). Grand Prix against five AI rivals at three levels, or Time Attack against your best-lap ghost. Realistic kart physics with holdable drifts. Keyboard, gamepad, or touch.

This repository only hosts the compiled game. Source: https://github.com/Cesardellantonio/tbc-kart
